== Общее описание

=== Назначение
Telegram-бот для автоматического мониторинга новостей о фигурках с отправкой уведомлений всем подписчикам о новых постах и темах.

*Целевые источники для мониторинга:*

* **BBS BBICN Forum** (https://bbs.bbicn.com/) - Специализированный форум коллекционеров фигурок
  - Обсуждения новых релизов от различных производителей
  - Обзоры и фотографии коллекционных фигурок
  - Информация о предзаказах и датах выхода
  - Пользовательские отзывы и рекомендации

* **Facebook Hot Toys** (https://www.facebook.com/hottoys) - Официальная страница производителя
  - Официальные анонсы новых фигурок от Hot Toys
  - Высококачественные фотографии продукции
  - Превью и тизеры предстоящих релизов
  - Обновления статуса разработки и производства

=== Цель проекта
Создать Telegram-бота, который будет регулярно парсить целевые источники, извлекать информацию о новых темах и постах, и автоматически рассылать уведомления всем подписанным пользователям в реальном времени.

=== Основные возможности
* Парсинг форума BBS BBICN и Facebook Hot Toys для извлечения новых тем и постов
* Автоматическая рассылка уведомлений всем подписчикам
* Управление подписками пользователей (подписка/отписка)
* Фильтрация контента по категориям и ключевым словам
* Административная панель для управления ботом
* Отложенная отправка сообщений для избежания спама

== Функциональные требования

=== Основные функции

==== Парсинг источников
* *Мониторинг разделов*: Отслеживание изменений в указанных разделах форума и социальных сетей
* *Извлечение тем*: Получение заголовков, авторов, дат создания новых тем и постов
* *Извлечение контента*: Получение содержимого постов, включая текст и изображения
* *Метаданные*: Сбор дополнительной информации (количество просмотров, ответов, лайков)
* *Дубликаты*: Исключение повторных уведомлений

==== Telegram Bot функции
* *Подписка/отписка*: Управление списком подписчиков
* *Массовая рассылка*: Отправка уведомлений всем активным подписчикам
* *Категории*: Подписка на конкретные категории (Hot Toys, ThreeZero, Sideshow)
* *Настройки*: Персональные настройки уведомлений
* *Модерация*: Административные команды

== Технические требования

=== Технологический стек

==== Backend (Go)
* *Язык*: Go 1.24+
* *Web Framework*: Echo v4 (для admin panel и health endpoints)
* *Telegram Bot API*: github.com/go-telegram-bot-api/telegram-bot-api/v5 (polling mode)
* *HTTP Client*: Standard net/http + context
* *HTML Parser*: github.com/PuerkitoBio/goquery
* *Social Media*: Facebook Graph API client
* *Database*: PostgreSQL 15+
* *ORM/Query Builder*: sqlc для type-safe SQL
* *Migrations*: golang-migrate
* *Configuration*: github.com/spf13/viper
* *Logging*: github.com/rs/zerolog
* *Monitoring*: Prometheus + Grafana

==== Инфраструктура
* *Контейнеризация*: Docker + Docker Compose
* *Environment*: Docker containers
* *CI/CD*: GitHub Actions
* *Admin Panel*: Веб-интерфейс для администрирования

title Последовательность обработки новых постов и уведомлений

participant "Polling Service" as PollingService

participant "Queue Manager" as Queue
participant "Message Formatter" as Formatter
participant "Telegram API" as TelegramAPI
participant "Subscribers" as Users

== Background Polling ==
note over PollingService: Polls every 1-3 seconds
PollingService -> TelegramAPI: getUpdates
TelegramAPI -> PollingService: Updates array

loop For each update
    PollingService -> UpdateProcessor: Process update
    UpdateProcessor -> CommandHandlers: Handle command/message
end

== Background Scraping ==
note over Scheduler: Runs every 5 minutes
Scheduler -> Scraper: Start scraping cycle

== Parse BBS Forum ==
Scraper -> BBSForum: GET forum pages
BBSForum -> Scraper: HTML content
Scraper -> Scraper: Parse new topics/posts

== Parse Facebook ==
Scraper -> Facebook: Graph API request
Facebook -> Scraper: JSON posts data
Scraper -> Scraper: Parse new posts

== Check for New Content ==
Scraper -> DB: Check for duplicates by hash
alt New content found
    Scraper -> DB: INSERT new topics/posts
    DB -> Scraper: New post IDs

    == Prepare Notifications ==
    Scraper -> NotifyService: Send notification request
    NotifyService -> DB: Get active subscribers
    DB -> NotifyService: Subscriber list

    loop For each new post
        NotifyService -> Formatter: Format message
        Formatter -> NotifyService: Formatted message

        loop For each subscriber
            NotifyService -> Queue: Add message to queue
        end
    end
end

== Message Processing ==
note over Queue: Background worker processes queue
Queue -> TelegramAPI: Send message
TelegramAPI -> Users: Deliver notification

alt Rate limit exceeded
    TelegramAPI -> Queue: Rate limit error
    Queue -> Queue: Re-queue with delay
else Success
    TelegramAPI -> Queue: Message sent
    Queue -> DB: Update notification status
end

Техническая спецификация описывает создание Telegram-бота для автоматического мониторинга и уведомления о новых постах с форума BBS BBICN и Facebook Hot Toys. Использование Go + Echo + PostgreSQL + Telegram Bot API обеспечивает высокую производительность, надежность и масштабируемость системы.

.Ключевые преимущества решения:

* Polling подход упрощает конфигурацию и отладку
* Гибкая система подписок по категориям
* Type-safe работа с базой данных через sqlc
* Высокая производительность с очередями сообщений
* Надежные retry механизмы для polling и уведомлений
* Полная контейнеризация с Docker
* Мониторинг и метрики из коробки
